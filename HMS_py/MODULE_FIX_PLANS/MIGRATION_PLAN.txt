1. GOAL
-------
VB6 HMS ke asli business behavior ko Python me migrate karna hai, bina schema-se-guesstimate ke. Live SQL Server database aur VB6 source logic ko authority maan kar migrate karna hi rule hai.

Rules:
- DB is source of truth.
- VB6 UI flow is behavior reference.
- Agar table VB6 me hai but live DB me nahi milti, to use nahin karna; dead placeholder ya safe viewer banana.
- Finance/accounting fields ko read-only rakhna agar live DB me sensitive fields hain.
- Menu, permissions, setup, and print/temp/report settings ko same style me reuse karna.

7. IMPORTANT NOTE FOR FUTURE CHANGES
------------------------------------
Any new port must follow this order:
1. Identify actual VB6 form or table name.
2. Check live SQL Server schema.
3. Map to exact Python file(s).
4. Write or update a focused regression test.
5. Implement the least-risk version that matches live behavior.
6. Run the focused unit suite before claiming the module is stable.
