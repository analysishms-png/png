PORTING RECIPE (har item ke liye same order - tests isi pe depend karte hain)
--------------------------------------------------------------------------------
1. SCHEMA PROBE FIRST
      db.query("SELECT TOP 1 * FROM <table>")
   -> table/column absent? status = BLOCKED-TBL, matrix me document karo,
      VB6 evidence ke saath (VB6 me bhi dead tha?), aur RUK JAO.
      KABHI table/column mat ghadna.
2. CORE  HMS_py/core/<domain>.py
   - VB6 Sub/Function body faithfully port karo.
   - fill-query copy karo: same WHERE / JOINs / ORDER BY (brackets for
     reserved words: [Option]).
   - save-sequence copy karo: same INSERT/UPDATE order + cn.commit().
   - helper names VB6 semantics ke naam rakho (Fill/Proc_341_20 -> auto_settle_pending jaisa).
   - Har write path me audit columns: U_Name, U_EntDt, U_AE ('A'/'E'/'D')
     + LogSite_Code. Missing = defect.
3. UI    HMS_py/ui/<domain>_ui.py
   - CRUD master  -> ui/base_master.py : BaseMasterForm + Field + MasterConfig
   - list/action  -> open_<name>(parent=None) factory returning the window
                     AND call .show() (shell return value discard karta hai -
                     warna form kabhi dikhega hi nahi, KI-8).
   - grid+buttons pattern VB6 DataGrid forms ke liye.
   - captions/labels/messages VERBATIM (VB6 typos included).
4. REGISTRY  ui/shell.py :: _form_registry()
   - key = EXACT VB6 menu caption.
   - real opener ko _coming_soon batch me mat daalo (wo baad me shadow kar deta hai).
   - tools/check_registry_shadow.py se verify karo.
5. VERIFY
      python -m py_compile <changed files>
      python -m pytest tests/unit -q
      python -m pytest tests/database -q
      python -m HMS_py.tools.manual_pipeline.run_module_tests --module <manual_id>
      + naya focused regression test (bina test ke DONE mat likho).

--------------------------------------------------------------------------------
CONVENTIONS / GOTCHAS
--------------------------------------------------------------------------------
- DB access sirf HMS_py/core/db.py se. Ek transaction me doosri connection
  mat kholo (self-deadlock observed).
- Registry lookup case-insensitive (_reg_ci) hai - menuHelp captions lowercase
  aati hain; plain dict.get() miss kar jata hai.
- VB6 BGR colours: &HCEE0C2& -> #C2E0CE (byte pairs reverse).
- menuHelp.Param_Str rights: 'AEDP' full; missing letter = no right;
  Flag 'V' = hidden; Flag '-'/'S' = separator (kabhi clickable nahi).
- Parallel agents is repo pe hain: change file-scoped rakho, module complete
  hote hi git add <files> && git commit.
- Live DB check read-only chalega; write test rollback/snapshot ke saath.
