1. USER LOGIN AND AUTHENTICATION WORKFLOW
==========================================

FRONTEND LOGIC:
-----------
1. User enters username/password on login page (index.html)
2. Frontend validates form inputs
3. AJAX call to backend/login.php with credentials
4. Backend connects to SunshineData2526 database
5. Query UserMast table for authentication
6. Check ActiveYN = 'Y' and encrypted password match
7. Create session and redirect to dashboard.html

BACKEND LOGIC:
-----------
TABLE: UserMast
FIELDS: USER_NAME, PASSWD (encrypted), LABEL, ShortName, ActiveYN

Login Process:
- SELECT USER_NAME, PASSWD, LABEL, ShortName FROM UserMast 
  WHERE USER_NAME = ? AND ActiveYN = 'Y'
- Decrypt provided password and compare with stored PASSWD
- If match: Create session with user data
- If fail: Return error message

Session Data:
- $_SESSION['username'] = USER_NAME
- $_SESSION['role'] = LABEL (0=Operator, 1=Administrator)
- $_SESSION['display_name'] = ShortName
- $_SESSION['logged_in'] = true

4. BOOKING AND RESERVATION WORKFLOW
====================================

FRONTEND LOGIC:
-----------
1. Booking Module (reservations.html)
2. Search available rooms form
3. Booking creation wizard
4. Guest details form
5. Payment and confirmation

BACKEND LOGIC:
-----------
MAIN TABLE: Booking
RELATED TABLES: BookingDetail, BookingPlanDetails, GrpBookingDetails

Booking Workflow:
Step 1: Check Room Availability
- SELECT Code, RoomCat FROM RoomMast 
  WHERE RoomStat = 'A' AND Code NOT IN (
    SELECT RoomNo FROM Booking 
    WHERE ArrDate <= ? AND DepDate >= ?
  )

Step 2: Create Booking Record
- INSERT INTO Booking (DocId, BookNo, VDate, ArrDate, DepDate, 
  RoomNo, GuestName, Adult, Child, NoDays, RoomRate, BookStatus)
- Generate unique DocId
- Set BookStatus = 'Confirmed'

Step 3: Create Booking Details
- INSERT INTO BookingDetail (Code, VenueCode, FuncDate)
- INSERT INTO BookingPlanDetails (BookingDocId, RateCode, RoomRate)

Step 4: Update Room Status
- UPDATE RoomMast SET RoomStat = 'O' WHERE Code = ?

Booking Status Flow:
- Inquiry → Confirmed → Checked-In → Checked-Out → Cancelled
