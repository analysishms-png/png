### VB6 vs Python Logic Mapping

#### VB6 MenuHelp Structure:
- Table: menuHelp (UserName, CompCode, Option, Param_Str, Flag, Module_Name, Opt1-Opt4)
- Param_Str = 4-char pattern (A/E/D/P) for Add/Edit/Delete/Print rights
- Flag values: E=Entry, R=Report, N=Node, V=Hidden
- User1 table: USER_NAME, SRNO (links to User_Module.srno for rights)

#### Python Port Evidence:
- menu.py:menu_name_allowed() - checks User1 + User_Module mapping
- menu_help.py:can_open() - checks menuHelp Flag (V=>never open, else AEDP check)
- menu_help.py:rights() - returns Param_Str or "AEDP" default
- menu_help.py:can() - case-insensitive right check in Param_Str

#### Dynamic Menu Regeneration (rebuild_menu_dynamic.py):
- Builds menubar from User_Module Module_Name groups
- Filters by user rights via user_allowed_srnos()
- Implements VB6 nesting: flag=1 => submenu; same-code flag=0 => children
- Default full access if User1 has no rows for user (SA 617/617 pattern)
