  1. GuestFolio INSERT pattern:

     DocId, FolioNo, Vtype='CHK', Vprefix, Vdate=getdate(),

     Site_Code, Vprefix, GuestProf, RoomNo, ChkInDate, ChkInTime='10:00',
     Adult=1, Children=0, DepDate, DepTime='10:00',
     Type='' (empty, NOT 'CHK' - varchar(1) truncation)

  5. FolioLog INSERT:

     FolionoDocid = GuestFolio.DocId
     Flag = 'A' (Added)

  6. Room assignment logic:
     If roomno provided: validate in RoomMast, check NOT occupied (RoomOcc ChkOutDate IS NULL)

  7. Validation:
     - Guest name required
     - Arrival <= Departure
     - Room must exist in RoomMast
     - Room must not be occupied

PART J: KEY BUSINESS RULES & STATE MACHINES
================================================================================

J1. GUEST LIFECYCLE STATE MACHINE
-----------------------------------
  [No Record] ──Booking──► [Booked] ──Check-In──► [In-House] ──Check-Out──► [Checked-Out]
       │                       │                       │                        │
       │                  [Cancelled]            [Amend Departure]        [Reverse Check-Out]
       │                  (Cancel='Y')          (GuestFolioAmend)        (ChkOutDate=NULL)
       │                       │                       │                        │
       │                       ▼                       ▼                        ▼
       │                  BookingCancelDetails    FolioLog flag='M'       FolioLog flag='R'
       │                  FolioLog flag='C'
       │
       └──No-Show──► (same as cancel, different CancellationMode)

J2. ROOM STATE MACHINE
------------------------
  RoomMast.Type: 'RO' (Regular Room), 'TB' (Tariff-Based)
  RoomOcc.Type:  '' (occupied, active), 'O' (checked-out)

  [Vacant-Clean] ──Check-In──► [Occupied] ──Check-Out──► [Vacant-Dirty]
       ▲                            │                         │
       │                     [Room Move]               [Housekeeping]
       │                     (RoomOcc update)          (RoomStat='C')
       │                            │                         │
       │                            ▼                         ▼
       │                     [New Room Occupied]      [Vacant-Clean]
       │
       └──────────────────────────────────────────────────────────

J3. FOLIO BALANCE STATE MACHINE
---------------------------------
  [Zero Balance] ──Room Charge──► [Positive (Guest Owes)]
       ▲                                │
       │                          [Payment Received]
       │                                │
       │                                ▼
       │                         [Zero Balance] ──Settle──► [SETTLED]
       │                                                        │
       │                                                  [FOMBillDetails]
       │                                                  Status='SETTLE'
       │
       └─────────────────────────────────────────────────────

J4. BOOKING CANCEL RULES (VB6 Evidence)
-----------------------------------------
  1. Cancel='Y' means cancelled (physical row stays - audit safe)
  2. Already-cancelled booking CANNOT be cancelled again (VB6 FGrid check)
  3. BookingCancelDetails row created with:
     - DocId = 'C' + original Booking DocId (truncated to 21)
     - CancelAmt = 0, Advance = 0
     - CancellationMode = 'Cancellation'
  4. BookingLog flag='C' for audit trail

J5. PAYCHARGE DOCUMENT NUMBERING
----------------------------------
  DocId format (21 chars):
    'D' + Site(2) + Vtype(LJUST-6) + Vprefix(LJUST-4) + VNo(RJUST-8)

  VNo = MAX(VNo)+1 within (Site_Code, Vprefix, Vtype)
  Python uses UPDLOCK+HOLDLOCK (VB6 didn't - race condition fix)

J6. PAYTYPE MAPPING (PayCharge)
---------------------------------
  KKCASH  → 'Cash'         (cash payment)
  KKCRED  → 'Company'      (company credit)
  KKVISA  → 'Credit Card'  (card payment)
  KK0006  → 'Other'        (other mode)
  KKRMCH  → 'Room Charge'  (charge to folio)
  KKCGSS  → 'CGST 5%'     (tax)
  KKSGSS  → 'SGST 5%'     (tax)

J7. GST CALCULATION
---------------------
  Room Charge:  Amount × 5% = CGST
  Room Charge:  Amount × 5% = SGST
  Total tax:    Amount × 10%
  Example: ₹3000 room → ₹150 CGST + ₹150 SGST = ₹3300 total

J8. AUDIT TRAIL PATTERN (ALL TABLES)
--------------------------------------
  U_Name    = current user
  U_EntDt   = getdate() (server timestamp)
  U_AE      = 'A' (Add) or 'E' (Edit)
  LogSite_Code = Site_Code

  Plus separate log tables:
  - FolioLog (FolioLog): Id, FolionoDocid, Flag (A/E/C/P/M/R/S)
  - BookingLog: Id, Bookingdocid, Flag (A/E/C)
  - LedgerLog: Full ledger audit trail
  - NightAuditLog: Audit run records

J9. FOLIO LOG FLAGS
---------------------
  'A' = Added (check-in)
  'E' = Edited (amend)
  'P' = Posted (charge)
  'C' = Checked-Out (settle)
  'M' = Modified (departure amend)
  'R' = Reverse Checkout
  'S' = Settled
